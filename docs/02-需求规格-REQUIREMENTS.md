### 2.1 任务管理（核心）

| **清单** | ✅ | 工作 / 生活（可扩展）；新建时的默认清单规则见 §2.3 | P0 |
| 状态 | ✅ | 待办 / 已完成 | P0 |
| 截止时间 | | 见下方"日期型 vs 时刻型 / 无日期" | P0 |
| 提醒时间 | | 默认规则见 §2.3 | P0 |
| 重复规则 | | 每天 / 每周 / 每月 / 每 N 天 | P1 |
| 排序 | ✅ | 手工拖拽 + 默认排序 | P1 |
| 重要 | | 布尔标记 | P2 |
| 已做次数 | ✅ | 重复任务累计完成次数 | P1 |
| 建立 / 完成 / 最后修改时间 | ✅ | 系统维护 | P0 |
| 删除标记 | ✅ | 软删除 | P0 |

**时间三态**

| 用户操作 | `due_has_time` | `due_at` | 默认 `remind_at` |
|---|---|---|---|
| 只点"明天" | 0 | 明天**本地 00:00** 的 UTC 值 | 明天**本地 09:00**（设置可改；已过则不排） |
| 点"明天 9:00" | 1 | 明天本地 09:00 的 UTC 值 | = `due_at` |
| **不设时间** | 0 | **NULL** → 归入「待定」视图 | NULL（不提醒） |

#### 2.1.2 操作

| 操作 | 入口 | 关键要求 |
|---|---|---|
| 新建 | 首页底部大 `＋` | 标题聚焦；回车即存；**除清单外不强制填任何字段** |
| 语音输入 | 首页独立 🎤（按住说、松手建）；编辑页 🎤 | 识别文本进标题；**永远可编辑**；无日期的落「待定」 |
| 编辑 | 点任务条目 | 打开"编辑/详情"**同一个**弹层 |
| 完成 | 条目左侧大圆点 | 一点完成；**弹撤销条**（5 秒） |
| 取消完成 | 已完成列表同圆点 | 回到待办；提醒未过则恢复通知 |
| 删除 | 编辑弹层底部 / 移动端左滑 | **直接删除 + 5 秒撤销** |
| 排序 | 列表长按拖动 | 仅在「全部」视图生效 |

### 2.2 视图（时间维度）

> 所有"今天/明天/本周/本月"边界均在**设备本地时区**计算，再转 UTC 比较（见 04 §六）。

| 视图 | 语义（均含 `deleted = 0 AND status = 0`，除非注明） | 默认显示 | 可否隐藏 |
|---|---|---|---|
| **待定** | `due_at IS NULL`（没写时间的） | ✅ | 可 |
| **今天** | `due_at IS NOT NULL AND due_at < 本地明天 00:00`（含逾期） | ✅ | 可 |
| **明天** | `>= 本地明天 00:00 AND < 本地后天 00:00` | ✅ | 可 |
| **本周** | `>= 本周一 00:00 AND < 下周一 00:00` | ✅ | 可 |
| **本月** | `>= 本月 1 日 00:00 AND < 下月 1 日 00:00` | ✅ | 可 |
| **以后** | `>= 下月 1 日 00:00` | ✅ | 可 |
| **全部** | `status = 0`，**按时间分组呈现**（逾期/今天/明天/本周/本月/以后/待定） | ✅ | **不可** |
| **已完成** | `status = 1` | ✅ | **不可** |

**关键性质**

1. **视图是过滤器，不是归属**：一条任务会同时出现在多个包含其日期的视图里（如 3 天后到期 → 同时出现在"本周"和"本月"）。
2. **视图随时间自动迁移**：3 天后到期的那条，到了那天自动进"今天"；没做完则逾期置顶标红。
3. **永不遗失**：`全部` 永远存在且不可隐藏，任何任务至少有一个地方能看到。
4. **默认打开「今天」**：首次进入选中"今天"（与产品核心一致）。标签栏默认顺序为 **今天 → 明天 → 本周 → 本月 → 以后 → 待定 → 全部 → 已完成**（"待定"是杂物筐，不占 C 位）。
5. **排序**：
   - 今天：`due_at ASC, sort_order ASC`
   - 明天/本周/本月/以后：`due_at ASC, sort_order ASC`
   - 待定：`created_at DESC`
   - 全部：按分组（逾期→今天→明天→本周→本月→以后→待定）；**组内按 `sort_order`（手工顺序，可拖拽）**
   - 已完成：`completed_at DESC`，默认加载最近 500 条 + "加载更多"

#### 2.2.1 视图管理（US-028，P1 / M4）

设置 → 视图管理，可对除锁定项外的所有视图：

- **显示 / 隐藏**（勾选）
- **上下排序**
- **重命名**（如把"本周"改成"这周"）

**锁定规则**：`全部`、`已完成` 不可隐藏（安全网）。
**校验**：隐藏项不影响数据，仅影响界面入口。

### 2.3 清单（维度正交，US-025）

- 内置两个清单：**工作**、**生活**（可新增，但默认不引导）。
- 首页提供**清单筛选**：`[全部] [工作] [生活]`，与时间视图是**乘法关系**：
  `本月 + 工作` = 本月的工作任务（月报就导这个）。
- 每张卡片/条目显示所属清单的小色点或标签（可关，避免杂乱）。
- **新建任务时的默认清单**：优先取当前清单筛选项；若筛选是「全部」，则取**上次使用的清单**（`last_used_list`），都没有则落**生活**。
- 导出支持按清单过滤。

### 2.4 提醒

#### 2.4.1 权限与平台前置条件

| 平台 | 权限 / 前置 | 用途 | 申请时机 | 被拒后的降级行为 |
|---|---|---|---|---|
| Android | `POST_NOTIFICATIONS`（API 33+） | 显示通知 | 首次排程提醒时 | 不显示通知；首页顶部提示条，点击跳设置 |
| Android | `SCHEDULE_EXACT_ALARM`（API 31+，**API 34+ 默认拒绝**） | 精确定时 | 首次排程精确提醒，跳系统页授权 | 降级 `inexactAllowWhileIdle`；设置页常驻"精确提醒未开启" |
| Android | `RECEIVE_BOOT_COMPLETED` | 重启后恢复定时 | 安装即声明 | 重启后提醒丢失；下次打开 App 重排 |
| Android | 通知渠道（channel） | **API 26+ 必须，否则通知不显示** | 启动时创建（id=`tasks`，high） | 无 |
| Android | `INTERNET` | 系统语音识别可能联网 | 安装即声明 | 无网时语音不可用，提示手动输入 |
| macOS | 麦克风（Info.plist + entitlement） | 语音输入 | 首次点 🎤 | 提示手动输入 |
| macOS | 语音识别（Info.plist） | 语音输入 | 首次点 🎤 | 同上 |
| macOS | 通知授权 | 提醒 | 首次排程提醒 | 不显示通知 |
| macOS | 用户选定文件读写 + security-scoped bookmark | 导出/自动备份目录 | 首次选目录 | 提示重新授权 |

#### 2.4.2 行为规则

| 项 | 需求 |
|---|---|
| 触发 | 到点弹系统本地通知 |
| 通知 ID | `tasks.notif_id`（自增整数），不用 UUID 哈希 |
| 交互 | 点通知 → 打开任务编辑弹层 |
| 已完成/已删除 | 取消其未触发的提醒 |
| 修改时间 | 取消旧通知 → 重排 |
| 重复任务 | **原地推进**：完成后把 `due_at` 推到“**当前时间之后第一个符合规则的时间点**”（逾期多期不逐格补，直接跳到下一个未来点），取消旧通知、排下一次（不用 `matchDateTimeComponents`） |
| 提醒时间已过 | 不排通知；编辑页提示"提醒时间已过，将不会提醒" |
| 撤销完成/撤销删除 | `remind_at` 在未来则重排；已过则不排并提示 |

### 2.5 无日期任务的提示（US-029）

因为"首页语音快速记"会产生无日期任务，必须有提示闭环：

| 提示 | 形式 | 可关 |
|---|---|---|
| 条目时间标签显示灰色「待定」 | 列表内视觉 | 否 |
| 保存时不设时间 → 底部轻提示"已存到「待定」，可随时补时间" | SnackBar（不阻拦） | 是 |
| 「今天」视图顶部汇总："还有 N 件没定时间 ›"（点击跳"待定"） | 顶部提示行 | 是 |
| 每周一次提醒整理"待定" | 本地通知（默认关） | 是 |

### 2.6 导出与备份

| 维度 | 选项 | 默认 |
|---|---|---|
| **范围** | 本周 / **本月** / 上周 / 上月 / 自定义（起-止） | **本月** |
| **清单** | 全部 / 工作 / 生活 | 全部 |
| **内容** | 仅已完成（可勾选追加"未完成 / 结转下月"章节） | 仅已完成 |
| **分组** | 按周 / 按日 / 不分组 | 按周 |
| **格式** | PDF（给人看）/ Markdown（写报告）/ JSON（全量备份） | Markdown |

> **「月报」预设按钮**：导出面板顶部提供一键预设 → `本月 + 工作 + 仅已完成 + 按周 + Markdown`。其余维度仍可改。全套文档中“一键出月报”均指此预设。

**三种格式的定位**

| 格式 | 用途 | 优先级 |
|---|---|---|
| **Markdown** | 直接复制进月报/周报 | P0 |
| **PDF** | 打印、给人看 | P0 |

## 三、数据需求

### 3.1 存储原则

1. 全部数据存本机；2. 单一 SQLite 文件；3. 写入即持久化；4. 软删除；5. UUID 主键；6. 时间以 UTC 毫秒存储，日界在本地时区计算。

### 3.2 数据实体

```
tasks     —— 任务（含 list 清单字段）
lists     —— 清单（工作/生活/…）
settings  —— 键值配置（含视图配置、device_id、notif_id 计数器）
```

详见 [05-数据模型](./05-数据模型-DATA-MODEL.md)。

## 五、验收标准（MVP 完成定义）

**MVP = M0 + M1（提醒部分）+ M2 + M3。**

- [ ] 无日期任务落「待定」，且有灰色标签 + 保存提示 + 今天页顶部汇总
- [ ] **首次打开默认落在「今天」**

- [ ] Android 13+ 通知权限、14+ 精确闹钟授权流程走通，被拒有降级提示
- [ ] 完成 / 撤销 / 编辑 / 删除 / 撤销删除（含通知重排取消）全部可用
- [ ] **「月报」预设（本月 + 工作 + 仅已完成 + 按周 + Markdown）** → 得到可直接写月报的文件
- [ ] 导出 PDF / Markdown / JSON 都能通过系统面板保存/分享并正常打开、中文不乱码
- [ ] 导出的 JSON 可重新导入且一致；导入**不改本机 device_id**
- [ ] 断网下除语音外全部可用；杀进程重开数据仍在
- [ ] 家人能在无讲解下完成"记一件事 + 设时间 + 完成 + 月底导出月报"
