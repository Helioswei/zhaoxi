## 决策速查（TL;DR）

| 维度 | 决策 |
|---|---|
| **名称** | **朝夕**（包名 `com.helioswei.zhaoxi`） |
| 用户 | 作者 + 家人，两人各自独立使用 |
| 平台 | Android（主）+ macOS 桌面 |
| 框架 | Flutter（与 yijing-app 同栈） |
| 存储 | Drift / SQLite，单文件，纯本地 |
| 同步 | **暂时不做**（架构预留，见 04 §十） |
| 语音 | 调用**系统**识别；可能走系统云端，因此声明 INTERNET 权限 |
| 导出 | PDF / Markdown / JSON，**P0 即可通过系统分享/保存拿到文件** |
| **视图** | 待定 / 今天 / 明天 / 本周 / 本月 / 以后 / 全部 / 已完成；**默认打开「今天」**；可显示隐藏、排序、重命名；**全部与已完成锁定** |
| **清单** | 工作 / 生活（与时间视图是**正交**的两维） |
| **导出默认** | 面板通用默认 = 本月 + 全部清单 + 仅已完成 + 按周；**「月报」预设** = 本月 + 工作 + 仅已完成 + 按周 + Markdown |
| 提醒 | 本地通知；Android 需 `POST_NOTIFICATIONS` + `SCHEDULE_EXACT_ALARM` + 通知渠道 |
| 重复任务 | **原地推进**（同一件事推进到下一次），非复制新记录 |
| AI | 暂不引入 |
| 变现 | 无，自用 |
| **MVP 边界** | **全部 P0 需求 = M0 + M1（提醒部分）+ M2 + M3** |
| 提前可日用版本 | **v0.1 = M0 + M1**（无语音、无导出） |
