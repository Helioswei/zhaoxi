## 一、待决策（需要拍板）

### D-1 视图精简 ✅ 已决策（2026-10-12）

**最终方案（已实现）**
- 视图只剩 **今天 / 接下来 / 已完成**；「全部」保留但**默认隐藏**（设置里可开）；
- **去掉「待定」**：任务必须有时间，新建默认今天；旧的无日期数据迁移到「今天」；
- 「接下来」内部按 **明天 / 本周 / 本月 / 更远** 分组；
- 逾期进「今天」顶部的**红色「逾期」分组**（不自动改日期）；
- 日期/时间选择器改为**中文**（`zh_CN` 本地化）。

以下为当时的分析过程，留作回溯：


**问题**：实测下来，「以后 / 待定 / 全部」显得重复。分析后确认：

- 「全部」在内容上 **= 其他所有视图的并集**（真正重复的那个）；
- 「以后」「待定」其实**不重复**（一个管"排到月底之后"，一个管"没定日期"），只是看着像杂物筐；
- 另一层重复感来自 **明天 ⊂ 本周 ⊂ 本月** 的嵌套——但这是刻意的（视图是过滤器，不是归属）。

**行业惯例**（调研，见下表）：主流 App 都只有 3–5 个时间视图，且**几乎没人把"明天/本周/本月"做成平级标签**——它们是"即将到来"这条连续时间线里的**分组标题**。

| App | 时间视图 |
|---|---|
| Things 3 | 收件箱 · 今天 · **即将到来** · 随时 · 某天 · 日志 |
| Todoist | 收件箱 · 今天 · **即将到来** |
| TickTick / 滴答清单 | 收件箱 · 今天 · 明天 · 最近 7 天 |
| Google Tasks | 今天 · **即将到来** · 所有任务 |
| Apple 提醒 | 今天 · 计划 · 全部 · 旗标 · 已完成 |
| Microsoft To Do | 我的一天 · 重要 · **已计划** · 全部 · 已完成 |
| OmniFocus | **预测** · 收件箱 · 项目 · 标签 · 回顾 |

**备选方案**

| 方案 | 视图集 | 说明 |
|---|---|---|
| **X（推荐）** | **今天 · 接下来 · 待定 · 已完成**（4 个） | 「接下来」内部按 `明天 / 本周 / 本月 / 更远` 分组；「全部」默认隐藏（安全网仍在，设置里可开） |
| Y | 今天 · 明天 · 本周 · 本月 · 已完成（5 个） | 去掉「以后/待定/全部」——**不可行**：无日期与远期任务会失去落点 |
| Z | 维持现状 8 个，用户自行隐藏 | 零改动，默认仍显多 |

**命名备选**

| 角色 | 备选 |
|---|---|
| 今天 + 逾期 | 今天 |
| 明天~未来 | **接下来** / 即将到来 / 计划 / 往后 |
| 无日期 | **待定** / 待安排 / 收件箱 / 没定时间 |
| 已完成 | **已完成** / 日志 / 做完了 |

**若采纳 X，改动范围**（增量很小，且是减法）

- 数据层：「接下来」= `dueAt >= 明天 00:00`，按 `dueAt` 排序；
- UI：复用「全部」已有的分组逻辑（明天/本周/本月/更远），只是分组标题替代标签；
- 「明天 / 本周 / 本月 / 以后 / 全部」从默认标签栏移除；
- 提醒、导出、拖拽排序、回收站、视图管理均不受影响；
- 同步修改 `02 §2.2`、`03 §3.1`、`05 §五`、`06`、`07`。

**最终决定**：采用 **X′（今天 / 接下来 / 已完成）**；命名即「今天 / 接下来 / 已完成」；「全部」保留但默认隐藏。另加：去掉「待定」、逾期红色分组、回收站 40 天、MD/PDF 支持「包含已删除」。
