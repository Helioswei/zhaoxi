**最终方案（已实现）**
- 视图只剩 **今天 / 接下来 / 已完成**；「全部」保留但**默认隐藏**（设置里可开）；
- **去掉「待定」**：任务必须有时间，新建默认今天；旧的无日期数据迁移到「今天」；
- 「接下来」内部按 **明天 / 本周 / 本月 / 更远** 分组；
- 逾期进「今天」顶部的**红色「逾期」分组**（不自动改日期）；
- 日期/时间选择器改为**中文**（`zh_CN` 本地化）。

以下为当时的分析过程，留作回溯：


**问题**：实测下来，「以后 / 待定 / 全部」显得重复。分析后确认：

- 「全部」在内容上 **= 其他所有视图的并集**（真正重复的那个）；
- 「以后」「待定」其实**不重复**（一个管"排到月底之后"，一个管"没定日期"），只是看着像杂物筐；
- 另一层重复感来自 **明天 ⊂ 本周 ⊂ 本月** 的嵌套——但这是刻意的（视图是过滤器，不是归属）。

**行业惯例**（调研，见下表）：主流 App 都只有 3–5 个时间视图，且**几乎没人把"明天/本周/本月"做成平级标签**——它们是"即将到来"这条连续时间线里的**分组标题**。

| App | 时间视图 |
|---|---|
| Things 3 | 收件箱 · 今天 · **即将到来** · 随时 · 某天 · 日志 |
| Todoist | 收件箱 · 今天 · **即将到来** |
| TickTick / 滴答清单 | 收件箱 · 今天 · 明天 · 最近 7 天 |
| Google Tasks | 今天 · **即将到来** · 所有任务 |
| Apple 提醒 | 今天 · 计划 · 全部 · 旗标 · 已完成 |
| Microsoft To Do | 我的一天 · 重要 · **已计划** · 全部 · 已完成 |
| OmniFocus | **预测** · 收件箱 · 项目 · 标签 · 回顾 |

**备选方案**

| 方案 | 视图集 | 说明 |
|---|---|---|
| **X（推荐）** | **今天 · 接下来 · 待定 · 已完成**（4 个） | 「接下来」内部按 `明天 / 本周 / 本月 / 更远` 分组；「全部」默认隐藏（安全网仍在，设置里可开） |
| Y | 今天 · 明天 · 本周 · 本月 · 已完成（5 个） | 去掉「以后/待定/全部」——**不可行**：无日期与远期任务会失去落点 |

**命名备选**

| 角色 | 备选 |
|---|---|
| 今天 + 逾期 | 今天 |
| 明天~未来 | **接下来** / 即将到来 / 计划 / 往后 |
| 无日期 | **待定** / 待安排 / 收件箱 / 没定时间 |
| 已完成 | **已完成** / 日志 / 做完了 |

**若采纳 X，改动范围**（增量很小，且是减法）

- 数据层：「接下来」= `dueAt >= 明天 00:00`，按 `dueAt` 排序；
- UI：复用「全部」已有的分组逻辑（明天/本周/本月/更远），只是分组标题替代标签；
- 「明天 / 本周 / 本月 / 以后 / 全部」从默认标签栏移除；
- 提醒、导出、拖拽排序、回收站、视图管理均不受影响；
- 同步修改 `02 §2.2`、`03 §3.1`、`05 §五`、`06`、`07`。

**最终决定**：采用 **X′（今天 / 接下来 / 已完成）**；命名即「今天 / 接下来 / 已完成」；「全部」保留但默认隐藏。另加：去掉「待定」、逾期红色分组、回收站 40 天、MD/PDF 支持「包含已删除」。

### D-6 动画体系（建议待拍板，2026-10-22 调研）

**调研结论**：项目目前没有自有动画体系，全靠 Flutter 默认（弹层上滑、snackbar、水波纹、拖拽跟随、唯一的 Dismissible）；用户最有感的时刻全是瞬变：勾完成、任务行出现/消失、弹层内展开备注/时间、切风格、深浅色切换。

**建议方案（克制路线，每处 ≤300ms，不弹跳不花哨，保持"松弛贴手"）**

核心三件（P1）：
1. **完成动画**：划线渐显 150ms（AnimatedDefaultTextStyle）+ 完成钮弹一下——"做完小事"的满足感，对家人最有价值的一处
2. **任务出现淡入+微上移** ~200ms：新建/undo 恢复的落定感（AnimatedList 或 itemBuilder 包 FadeTransition）
3. **弹层内展开/收起**：时间/重复/备注 AnimatedSize ~200ms

顺带（P2）：
4. 切风格/深浅色全程渐变（新版 Flutter theme 切换动画 API，成本低）
5. 筛选 pill 选中 150ms 过渡

量级：P1 约半天，P1+P2 约一天。待用户拍板范围后实施。

### T-9 说明（系统文件选择器问题）

现象：在部分国产 ROM 上，系统「文件」选择器的**目录名/文件名/侧栏名称全部不显示**（只剩图标），
侧栏还固定出现 音频/视频/图片。这是 DocumentsUI 的渲染问题，App 无法改变。

现状与绕过：
- 自动备份列表（备份与恢复页底部）可**直接分享/恢复**，不经过选择器；
- 「选择备份文件…」仍可用，但在这类机型上体验差。

建议方案（待做）：注册 `ACTION_SEND` / `ACTION_VIEW`（`application/json`、`text/plain`、
`application/octet-stream`），用 `receive_sharing_intent` 接收后复用现有「合并 / 覆盖」弹窗。
用户流程：微信收到 json → 分享/用其他应用打开 → 朝夕 → 合并或覆盖。
