# 朝夕 — 功能设计（交互与界面）

> 版本：v0.5
> 日期：2026-10-12
> 状态：待评审（已吸收评审意见 + 真实使用场景补充）
> 依赖：[02-需求规格](./02-需求规格-REQUIREMENTS.md)

---

## 一、设计原则

1. **一屏一件事** —— 首页就是清单，不嵌套、不抽屉。
2. **能说就别点，能点就别打字** —— 首页可直接说话；时间用大按钮。
3. **不解释也能懂** —— 图标用通用语义；文案用日常中文。
4. **错了能回来** —— 完成、删除可撤销（5 秒）；隐藏的视图可在「视图管理」里随时勾回。
5. **永不遗失** —— 任何任务至少有一个视图能看到它。

| 项 | 规范 |
|---|---|
| 主色 | 浅 `#3B7A6E`（5.01:1）／深 `#6FBFAE` |
| 字号 | 正文 ≥ 16，任务标题 18，按钮文字 17 |
| 圆角 | 卡片 16，按钮 12–999 |
| 间距 | 8 的倍数 |
| 点击区 | 最小 44×44 |
| 动效 | 150–250ms |

## 二、信息架构

```
App
├── 首页（清单）
│   ├── 第 1 行：清单切换   [全部] [工作] [生活]
│   ├── 第 2 行：时间视图   [今天][接下来][已完成]（横向可滑，默认选中「今天」；「全部」默认隐藏）
│   ├── 任务列表
│   └── 右下：大 ＋
├── 新建 / 编辑弹层（同一个）
└── 设置
    ├── 外观
    ├── 视图管理
    ├── 清单管理
    ├── 提醒
    ├── 数据（导出/导入/备份）
    └── 关于
```

## 三、页面设计

### 3.1 首页

```
┌─────────────────────────────────────────┐
│  朝夕                              ⚙️    │
├─────────────────────────────────────────┤
│  [ 全部 ]  工作   生活                   │  ← 清单筛选
│  ●今天  接下来  已完成                             │  ← 横向可滑（当前=今天）
├─────────────────────────────────────────┤
├─────────────────────────────────────────┤
│  ○  交材料                    ·工作 今天 9:00│
│  ○  买菜                      ·生活 今天    │
│  ○  取快递                    ·生活 昨天    │  ← 逾期标红
│  …                                      │
│                            ╭────╮       │
│                    ╭────╮  ╰────╯       │
│                    │ ＋ │               │
│                    ╰────╯               │
└─────────────────────────────────────────┘
```

- **清单色点**：工作=蓝、生活=绿（可关）。
- 时间标签颜色：逾期 → `#B3261E`；今天 → 温馨点缀色（温润风格下为暖橘）；更远 → 次级灰 `#667085`。
- **「今天」分两组**：逾期（红色分组头，含更早所有未完成）+ 今天；**逾期不会消失、也不会自动改日期**。
- **「接下来」分四组**：明天 / 本周 / 本月 / 更远（`更远` = 下月及以后）。
- 条目交互同前：点圆点完成、点条目编辑、长按拖动排序、左滑/悬停删除。

**悬浮按钮**：`＋`（新建，直径 60，右下角）。

**空状态**：
- 今天为空 → "今天没有安排"（🍵 插画 + "要不要记一件小事？"）
- 接下来为空 → "接下来没有安排"（🌤️ 插画）
- 已完成为空 → "还没有完成的任务"（✅ 插画）

### 3.2 新建 / 编辑任务（同一弹层）

```
┌─────────────────────────────────────────┐
│  新建任务                          ✕    │
├─────────────────────────────────────────┤
│  清单    [ 工作 ] [ 生活 ]               │  ← 默认取当前清单；筛选为「全部」时固定「工作」
│  标题                                    │
│  ┌───────────────────────────┬────────┐ │
│  │ 输入标题…                  │        │ │
│  └───────────────────────────┴────────┘ │
│  时间                                    │
│  [ 今天 ] [ 明天 ] [ 后天 ] [ 下周 ] [选…]│  ← 高 44，默认「今天」
│  提醒： [ 准时 ] [ 提前15分 ] [ 提前1时 ] │
│  ⓘ 只选日期时，默认当天 09:00 提醒        │
│  重复（P1） [ 不重复 ][ 每天 ][ 每周 ][ 每月 ]│
│  备注（默认收起）                         │
│              [   保存   ]                │
│           删除这条任务（红字，仅编辑态）    │
└─────────────────────────────────────────┘
```

**保存规则**
- 标题非空即可保存；**时间默认今天**（只选日期则 09:00 提醒），可改。
- 标题为空点保存 → 抖动 + "写点什么呢？"。
- **没有「不设时间」**：任务必须有时间（见 02 §2.5）。

### 3.3 编辑已有任务 / 详情（与 3.2 同一弹层）

同一弹层内追加：只读的创建/完成时间、已做次数（重复任务）、"标记为未完成"、底部红字删除。不单独做详情页。

### 3.4 视图管理（US-028 / M4）

```
设置 → 视图管理
  ⇅ ☑ 今天      🔒 不可隐藏
  ⇅ ☑ 接下来    重命名
  ⇅ ☑ 已完成    🔒 不可隐藏
  ⇅ ☐ 全部      重命名（默认隐藏）
```

- 拖动排序、勾选显示、点击重命名。
- 锁定的「今天 / 已完成」灰显勾选框，提示"为保证不漏任务，此项必须显示"。
- 隐藏只影响入口，不影响内容与导出。

### 3.5 清单管理

- 默认两个：**工作 / 生活**，各一色；**可改名、改色，但不可删除**（保证月报永远有"工作"可筛）。
- **自定义清单**可新增（如"买菜"）、改名、改色、删除；**删除前必须让用户选择其任务的归属清单**（默认"生活"）。
- 不强制引导用户创建，保持"能少则少"。

### 3.6 设置

| 分组 | 项 |
|---|---|
| 外观 | 主题、字号 |
| 视图 | 视图管理（见 3.4） |
| 清单 | 清单管理（见 3.5） |
| 提醒 | 默认提前量、日期型默认提醒时刻、通知/精确提醒状态 |
| 数据 | **「导出月报」主按钮** → 弹层；**备份与恢复**（单独页）；**回收站**（40 天自动清理） |
| 关于 | 版本、开源许可（含思源宋体 OFL）、"数据不会离开本机" |
| **危险** | **回收站**（保留 40 天，超期自动清理；可恢复/彻底删除）、**清空数据**（见下） |

**「清空数据」语义（不可逆，唯一定义处）**

- 范围二选一：`仅任务与清单`（tasks + lists）/ `全部（含设置与视图偏好）`。
- **必须二次确认**（勾选"我知道无法恢复"）。
- 执行前**先取消全部已排程通知**，再清空。
- 默认提供"**清空前自动导出一份 JSON**"（可取消勾选）。
- `device_id` 与 `notif_id_counter` 始终保留。

## 四、关键流程

### 4.1 语音输入（已取消）

2026-10-18 移除：依赖系统识别服务、部分机型不可用，且多数输入法本身带语音键。
首页与编辑页都不再有麦克风按钮；App 不申请麦克风/联网权限。

### 4.2 完成与撤销
```
点圆点 → 变灰划线 → 淡出 → SnackBar"已完成 ✓ 撤销"（5 秒）
       → 撤销 → 恢复；提醒未过则重排，已过则不排
```
重复任务：`due_at` 推进下一次、`completed_count+1`、排下一次通知，不进已完成列表。

### 4.3 删除与撤销
```
删除 → 淡出 + SnackBar"已删除 撤销"（5 秒）→ deleted=1，取消通知
     → 撤销 → deleted=0，提醒未过则重排
```

### 4.4 导出月报（方案 B：默认极简，选项可展开）

**设计原则**：月报是太太每月用一次的事，页面上只放她必须做的选择；低频项收进「更多选项」。

```
设置 → 数据 → 导出（列表项，与「备份与恢复」「回收站」同一样式）
   ↓ 跳转到「导出」页（顶部可返回，底部固定操作条）
   哪一段时间   [本周] [本月✓] [上周] [上月] [自定义]
   哪些清单     [全部] [工作✓] [生活]
   格式         [PDF✓] [Word] [Excel] [MD] [复制]      ← 一行 5 个等宽
   内容         [仅已完成] [已完成 + 未完成✓]
   已删除       [不包含✓] [包含]
   ↓
   [ 分享 / 发送 ]        ← 主按钮
   [ 存到文件夹… ]        ← 次按钮（选「文字」时不显示）
```

**两个按钮的区别**

| | 分享 / 发送 | 存到文件夹 |
|---|---|---|
| 弹窗 | 系统分享面板（微信、邮件、WPS、保存到文件…） | 系统保存对话框（选目录 + 文件名） |
| 文件去哪 | 交给目标 App 决定 | 你指定的文件夹 |
| 用途 | 发给别人 / 发给自己 / 用 WPS 打开 | 长期归档 |

**行为**
- 格式决定产物：`PDF→.pdf`、`Word→.docx`、`Excel→.xlsx`、`MD→.md`；**「复制」= 复制到剪贴板**（不产生文件，主按钮变成「复制文字」）；
- **分组自动决定**：范围 ≤14 天按日、否则按周——用户不需要再选（「哪一段时间」已经决定了粒度）；
- 默认：`本月 + 工作 + 已完成（含未完成章节）+ PDF`；
- 范围为空时提示"这个时间段没有符合条件的记录"；
- **JSON 备份不在这个弹层里**，见 4.5。

### 4.5 备份与恢复（独立页，低频）

| 区块 | 内容 |
|---|---|
| 备份全量数据 | 「分享备份文件（JSON）」/「存到文件夹…」；含全部任务（含已删除）与清单，不含设备标识 |
| 从备份恢复 | 选择 JSON → 弹窗选「合并」或「覆盖」（覆盖需二次确认；先取消全部通知，导入后重排） |
| 自动备份 | 显示"共 N 份 / 最近一次 …" + 「立即备份」；每天首次打开自动备份，保留 14 份 |

### 4.6 导入恢复（细节）
```
选择 JSON → 校验 exportFormatVersion
   ├─ 版本更新 → 拒绝
   ├─ 结构不合法 → 拒绝
   └─ 合法 → [ 合并（推荐） ] / [ 覆盖全部 ] → "已导入 N 条"
```
合并按 `id`、`updated_at` 大者胜；**绝不覆盖 `device_id` / `notif_id_counter` / 视图配置**。

## 五、边界与异常

| 情况 | 处理 |
|---|---|
| 标题超长 | 按字素簇限 200，提示 |
| 备注超长 | 按字素簇限 2000 |
| 未选时间 | 默认今天（不再允许无日期任务） |
| 时间设为过去 | 允许（逾期），提示"这个时间已经过了" |
| 提醒时间已过 | 不排通知，编辑页提示 |
| 通知权限被拒 | 首页顶部提示条 |
| 精确闹钟被拒 | 设置页常驻"精确提醒未开启"+ 跳转 |
| 试图隐藏"全部/已完成" | 禁止，提示原因 |
| macOS 备份目录授权失效 | 提示重新授权 |
| 导出范围为空 | 提示"这个时间段没有符合条件的记录"（仅已完成→"没有已完成的记录"；含未完成→"没有符合条件的记录"） |
| 导入文件 > 50MB | 拒绝 |

## 六、视觉规范

### 6.1 颜色（已按 WCAG AA 实测，标注基准背景）

| 用途 | 浅色 | 基准背景 | 对比度 | 深色 | 基准背景 | 对比度 |
|---|---|---|---|---|---|---|
| 背景 | `#F7F8FA` | — | — | `#121316` | — | — |
| 卡片 | `#FFFFFF` | — | — | `#1C1E22` | — | — |
| 主色 | `#3B7A6E` | 卡片 `#FFFFFF` | 5.01 ✅ | `#6FBFAE` | 卡片 `#1C1E22` | 7.74 ✅ |
| 逾期/危险 | `#B3261E` | 卡片 `#FFFFFF` | 6.54 ✅ | `#FF6B6B` | 卡片 `#1C1E22` | 6.01 ✅ |
| 主文字 | `#1A1A1A` | 背景 `#F7F8FA` | 16.38 ✅ | `#EDEDED` | 背景 `#121316` | 15.87 ✅ |
| 次文字 | `#667085` | 背景 `#F7F8FA` | 4.68 ✅ | `#9BA1AA` | 背景 `#121316` | 7.14 ✅ |
| 清单·工作 | `#3B6EA5` | 卡片 `#FFFFFF` | 5.30 ✅ | 亮版 | — | — |
| 清单·生活 | `#3B7A6E` | 卡片 `#FFFFFF` | 5.01 ✅ | 亮版 | — | — |

> 次文字从 `#6B7280`（4.55，余量仅 0.05）提到 `#667085`（4.68，余量 0.18），避免列表渲染在浅色背景上时跌破 4.5。清单色为弱信息、不承载文字，对比度另作校验。

### 6.2 字体
界面用系统字体；PDF 导出使用打包的 `ZhaoxiSerif-Regular.ttf`（思源宋体 TrueType 子集，**SIL OFL-1.1**，随包附带许可证文本并在「关于 → 开源许可」列出）。

### 6.3 组件

| 组件 | 规范 |
|---|---|
| 任务条目 | 高 ≥ 56，圆点 24，标题 18，时间 14 |
| 主按钮 | 高 52，圆角 12 |
| 快捷按钮 | 高 44，胶囊 |
| 视图标签 | 视觉高 36、**点击区 ≥ 44**（上下 padding 撑开），横向可滑，选中态下划线/填充 |
| 悬浮 ＋ | 60 |
| SnackBar | 底部，含撤销 |

> 表中尺寸均为**点击区**；若视觉尺寸更小（如视图标签），用 padding 补足到 44。

### 6.4 桌面端
`⌘N` 新建、`Enter` 保存、`Esc` 关闭、`⌘Z` 撤销、`/` 搜索；窗口最小 480×600；条目 hover 显示删除。

**搜索（M4）**：顶部放大镜（或 `/`）。关键词匹配**标题或备注**，且**跨全部视图、包含已完成**——不局限于当前视图或清单（否则在「今天」里永远搜不到下周的事）。最多返回 200 条，按最近修改倒序。
