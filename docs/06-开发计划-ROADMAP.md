## 一、总原则

1. **每个里程碑都要能跑**：M0 结束就能真正用来记事。
2. **需求可追溯**：每个任务挂 `US-xxx`（见 02 §一），P1/P2 明确标注。
3. **先窄后宽**：先 Android 跑通，再补 macOS（但 M0 期间先跑通一次 macOS 构建）。
4. **文档随代码更新**：决策变了就改 `docs/`。

### 1.1 里程碑与优先级对照

| 里程碑 | 内容 | 对应优先级 |
|---|---|---|
| M0 | CRUD + **清单** + **8 视图** + 无日期提示 + 主题 + 双端跑通 | P0 |
| M1 | 提醒 + 排序 | 提醒=P0，排序/偏移=P1 |
| M2 | ~~语音输入~~（已取消） | — |
| M3 | 导出（**范围/清单/内容/分组**）/ 导入 / 备份 | 导出导入=P0，自动备份=P1 |
| M4 | macOS 打磨 + **视图管理** + 深色 + 搜索 + 重复任务 | 全部 P1 |
| M5 | 登记项 | P2/P3 |

**MVP = 全部 P0 = M0 + M1（仅提醒部分）+ M2 + M3。**
**v0.1 可日用版本 = M0 + M1**（无导出），先用两周再决定 M2/M3 谁先。
