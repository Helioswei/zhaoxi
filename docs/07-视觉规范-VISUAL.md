## 一、为什么做成"可切换的风格"

不同人对"好看"的判断差别很大，尤其本项目真正的用户是家人。所以：

- 视觉不写死在一处，而是抽成 **一套令牌（tokens）**；
- 令牌有 **3 套预设**，在 **设置 → 外观 → 风格** 里**实时切换**；
- 组件只从令牌取色与形状，**换风格不动任何业务代码**。

```
AppStyleId (fresh | warm | paper)
        ↓  tokensFor(style, brightness)
AppTokens  ← ThemeExtension，挂在 ThemeData 上
        ↓
context.tokens.xxx  ← 所有组件从这里取
```

代码：`lib/ui/theme/app_style.dart`（令牌与预设）、`lib/ui/theme/app_theme.dart`（组装 ThemeData）。

## 二、三套预设

| id | 名称 | 一句话 | 关键特征 |
|---|---|---|---|
| `fresh` | **清爽** | 简洁克制，信息优先 | 冷灰底 + 白卡 + 小圆角(16) + 无阴影 |
| `warm` | **温润** | 奶油底 · 大圆角 · 暖橘点缀 | 奶油底 + 大圆角(22) + 轻阴影 + 暖橘"今天" |
| `paper` | **纸感** | 米白纸底 · 衬线字 · 朱砂茶金 | 纸底 + 衬线（思源宋体子集）+ 茶金主色 + 小圆角(12) |

## 三、字体

| 用途 | fresh / warm | paper |
|---|---|---|
| 界面字体 | 系统默认（Android: Noto Sans CJK / macOS: PingFang SC） | `ZhaoxiSerif` = 打包的思源宋体子集 |
| 页面标题 | 22 / w700 | 同 |
| 任务标题 | 17 / w600 | 同 |
| 辅助文字 | 13 | 同 |
| 胶囊/标签 | 12–14 | 同 |

- 衬线字体与 PDF 导出**共用同一份子集**（`assets/fonts/ZhaoxiSerif-Regular.ttf`，由 `tool/build_pdf_font.py` 生成，SIL OFL-1.1）。
- 子集覆盖 GB2312 + ASCII + 常用标点，界面文案全在其中；**emoji 会回退到系统** emoji 字体（正常）。

## 四、组件规范

| 组件 | 类 | 规范 |
|---|---|---|
| 筛选/视图胶囊 | `AppPill` | 无边框；未选中=透明底+次文字色；选中=`chipSelectedBg` 底 + 主色文字 + w600；圆角=胶囊 |
| 信息小胶囊 | `AppBadge` | 12px 文字；底色 = 该色 12% 透明；圆角=胶囊。用于时间、逾期 |
| 任务卡片 | `Card` + 内边距 10/14 | 每张卡片上下外边距 4、左右 12；圆角=`cardRadius`；左侧完成圆点 26px |
| 空状态 | `AppEmptyState` | 96px 圆形浅底 + emoji（40px）+ 主文案（16/w600）+ 可选提示（13） |
| 悬浮按钮 | ＋ / 🎤 | 都是圆形主色；＋ 直径 56、🎤 56；白色图标 |
| 底部弹层 | 编辑/新建 | 顶部圆角=`sheetRadius`；标题 20/w600 |
| 分组头 | 「全部」视图 | 12px / w700 / letterSpacing 0.6 / 次文字色 |

**触达尺寸**：所有可点元素的有效点击区 ≥ 44×44（Material `padded` 保证 48）。视图/筛选胶囊用内边距撑开。

## 五、动效

| 场景 | 时长/曲线 |
|---|---|
| 通用状态变化 | 200ms · easeOut |
| 完成勾选 | 圆点颜色切换 + 列表项淡出（默认 Material 行为） |
| 弹层 | 系统默认（bottom sheet） |
| 页面切换 | 系统默认 |

原则：**只为表达状态变化，不做装饰性动画**。

## 六、无障碍

- **字号**：设置 → 外观 → 大字号（在系统缩放基础上 ×1.2）。
- **点击区**：≥44。
- **对比度**：正文 ≥4.5:1（各预设已按此挑选；新增色值需实测）。
- **语义**：图标按钮都有 `tooltip`/`Semantics` 标签。

---

## 七、怎么加一套新风格

1. 在 `AppStyleId` 加一个枚举值（id / 名称 / 描述）；
2. 在 `tokensFor()` 里补该风格的**明+暗**两份令牌；
3. 若用自定义字体，在 `pubspec.yaml` 注册并在令牌里写 `fontFamily`；
4. 跑一遍 `flutter test`（`style` 相关单测会覆盖枚举完整性）；
5. 在真机/模拟器上截图对比，确认对比度与点击区。

> 令牌之外的改动（新增组件、改布局）应尽量也走 `context.tokens`，避免某套风格漏改。
